# Aetheria Gastronomy | Velorah®

A responsive, 2026-themed futuristic restaurant website featuring 3D design, stylish animations, and a secure administrative nexus.

## Features

- **Futuristic 3D Hero**: Interactive Three.js orbital sphere and particle system.
- **Cinematic Visuals**: Smooth crossfade video transitions and blur-in text animations.
- **Dynamic Menu**: "Synthetic Savor" digital codex driven by a REST API.
- **Liquid-Glass Design**: Ultra-modern UI system using Tailwind CSS.
- **Dual-Theme Support**: Dark/Light mode toggle with persistence.
- **Admin Nexus**: Secure portal for updating system credentials.

## Tech Stack

- **Frontend**: Vanilla HTML/JS, Tailwind CSS, Three.js
- **Backend**: Node.js, Express
- **Data**: JSON-based dynamic content

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the orbital server:
   ```bash
   npm start
   ```

3. Access the experience:
   Visit `http://localhost:3000` in your terminal.

## Administrative Access

The Admin Nexus can be reached at `/admin`. Default credentials are provided in the setup documentation.
